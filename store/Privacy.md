# Folio 隐私政策（Mac App Store 版）

Folio 在你的 Mac 上打开、搜索和编辑本地文件。文件内容、文件名、文件路径和搜索词都在本机处理，Folio 不会把这些内容发给开发者或 AI 服务。使用 Folio 无需注册账号。商店版不包含广告、分析 SDK 或跟踪功能。

当你选择文件或项目目录时，Folio 使用 macOS 授予的访问权限。为便于下次打开，项目路径、打开的标签和安全范围书签保存在应用的本地设置中。商店版由 Mac App Store 提供更新。

点击文档中的外部链接或选择在浏览器打开 HTML 时，Folio 会按你的操作调用默认浏览器。若你主动在公开的 GitHub Issues 反馈问题，请避免上传私人文件或敏感内容。

有关此政策的问题，可通过 [Folio 项目的支持页面](https://github.com/moosl/Folio/issues) 联系维护者。
